# Project Overview:
The DARG website is a responsive website designed for the Domestic Animal Rescue Group(DARG), an organisation dedicated to rescuing, caring for, and rehoming abandoned and neglected animals.
The purpose of the website is to provide visitors with an easy and engaging way to learn anou DARG, view animals available for adoption, support the organisation, shop, and find important contact and location information.

# Project Goals:
* Provide information about DARG and its animal rescue services.
* Help users discover animals available for adoption.
* Encourage visitors to volunteer and support the organisation.
* Provide information about the DATH Coffee Shop.
* Allow user to brower products through the online shop.
* Make it easy for visitors to find DAR's location and contact details.
* Create a user-friendly and responsive experience across different devices.
* Increase awareness of animal rescue and adoption

# Key Functionality:
* Responsive Navigation: Users can easily navigation between the different pages of that website using the main navigation menu:
* Animal Adoption: Users can view information about animals available for adoption and learn more about the adoption process.
* Volunteer Information: Users can learn how to become a volunteer and find information anout getting involved with DARG.
* Coffee Shop: Users can view information about the DARG Coffee Shop.
* Online Shop: Users can browes products available through the DARG online shop and support the organisation through purchase.
* Donations:The website will provide users with information on how they can finacially support DARG and contribute towars the care of rescued animals.
* Find us: Users can easily find DARG's location through an embedded map, address and catact information.
* Contact Information: Visitors can access DARG's contact details and communicate with the organisation for assistance.
* Resposive Design:The website will be designed to work effectivelt across desktops, tablets and mobile devices.
* Easy NAvigation: A clear navigation structure will allow users to quickliy access important sections of the website.
